首頁讀取 GitHub 已發布的證交所正式收盤、期交所 TX 夜盤日報及國際市場延遲日線。手動更新會另外向證交所 MI_INDEX 查詢最新已公布的正式收盤，並顯示取得新資料、無新資料或查詢錯誤。頁面同時檢查 Pages 與儲存庫公開資料，讓資料更新不必等待 Pages 網頁部署。

每日收盤指數優先使用證交所 MI_INDEX，成交金額由 FMTQIK 發布後補上。GitHub Actions 可能延遲。休市時如無新行情，沿用最近有效資料。TX 使用期交所官方盤後報表的歸屬日，並以同契約夜盤開盤當日的日盤結算價核對漲跌。夜盤報表僅提供時段截止及最後成交價，未提供最後一筆成交時刻。台股日盤及台指期夜盤的半小時行情仍需可公開轉載的授權來源。

個股健檢為既有的健檢項目介面，個人資產頁仍為既有的待開放頁面。配息目標可在目前瀏覽器儲存設定。

08:40 提交盤前工作，08:42 提供第二次機會。僅在 08:45 前完成資料擷取且開盤前寫入的預測可鎖定。08:45 這一分鐘以外鎖定的預測會標示延遲，不列入統計。鎖定時刻與 GitHub 發布時刻可能不同。方向規則為上漲／下跌，震盪以鎖定時記錄的 ±0.30% 判定。沒有足夠樣本進行機率校準。

## V3.17 行情排程

每天每小時的第 7、37 分（UTC）預定刷新，共 48 次，包含週末。第 22、52 分檢查上一個主工作，找不到成功紀錄即補查。每次刷新在 Actions 摘要和 30 天保存的 JSON 產物保留各市場結果及實際時間。行情不變時不建立資料提交。工作流程失敗時，仍提交同輪已確認的其他市場；同一資料檔的非快轉衝突會重新讀取 main 再嘗試。

國際市場使用交易所當地時區判斷已完成的日線。Yahoo Finance 日線屬延遲資料，兩個主機為同一提供者，可處理其中一個主機出錯。盤前鎖定要求四項美股來源全部對應上一個美國交易日。美國休市表依 NYSE 公告，包含 2026 至 2028 年。手動按鈕可直接查證交所正式收盤，其他市場讀取後台已更新的 JSON。沒有公開盤中來源的市場目前僅顯示已完成交易時段資料。

補查工作會自動保存滾動 24 小時稽核，從 GitHub 的自然排程紀錄統計 48 個時段，標示成功、失敗、執行中與未觀測，並檢查最近兩個主排程。此稽核以 GitHub 的工作建立時間歸屬時段，部署前或延遲跨時段的紀錄可能顯示未觀測。
